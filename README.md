# MultiEmulator Web

koitanのGame Boy / Game Boy Color / Game Boy Advance / ファミコン / スーパーファミコンエミュレータのWeb/PWA配布ファイルです。SFCは基礎実装段階です。

## 起動

https://tk-koitan.github.io/MultiEmulator-Web/

WebGPU対応のブラウザで開いてください。R3 / Esc（タッチ操作ではメニュー）から「ROMを開く」を選び、手元の `.gb` / `.gbc` / `.gba` / `.nes` / `.fds` / `.sfc` / `.smc` を読み込みます。SFCはLoROM / HiROM、65C816、背景Mode 0〜7、HDMA、ウィンドウ・色合成・モザイク・高解像度表示、スプライト、入力・ステートの基礎実装です。SPC700／DSP音源とコンピュートシェーダー描画に試験対応しています。SFCのローカル2人プレイに対応し、設定の「FC・SFCの操作デバイス」から1P・2Pにパッド・キーボード・画面ボタンを割り当てられます。描画の一部・特殊チップ・オンライン通信は未対応です。ファミコンはNTSCのNROM・MMC1/2/3/4・UxROM・CNROM・AxROM・GxROM・Bandai FCG・VRC2/4/6に試験対応しています。対応基板のNES 2.0形式も読み込め、VRCのサブマッパーとRAM容量の指定を扱います。ディスクシステム（FDS）は内蔵HLEで起動でき、設定から外部BIOS（8 KiB）も取り込めます。メニューからディスクを取り出し・面切り替えできます。ファミコン／FDSはオンライン2人プレイに対応しています。FDSでは同じディスクイメージ・BIOS方式を選び、ホスト側でディスク操作を行います。GBAのローカル通信は設定で2〜4台、オンライン通信はルーム作成時に2〜4人を選べます。オンラインでは全員が全参加者のROMを手元のライブラリに登録し、準備完了を押してください。

## インストール

Chrome / Edgeのアドレスバーやブラウザメニューからアプリとしてインストールできます。初回はインターネットに接続し、本体のダウンロードとオフラインキャッシュが完了するまでページを開いておいてください。以降はオフラインでも、保存したROMをROMライブラリから開いて遊べます。オンライン通信にはインターネット接続が必要です。

## 保存

ROM、ゲーム内セーブ、スクリーンショット付きセーブスロット、履歴、設定は端末のブラウザ内に保存されます。PWAからの起動時に永続保存を要求します。ブラウザやOSが許可を判断します。サイトデータの削除で保存内容も消えるため、大事なセーブは取り扱いにご注意ください。

配布内容はビルド済みWebプレイヤー、PWA設定、アイコン、オフライン起動用ファイルです。
